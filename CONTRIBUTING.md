# Contributing to Wiremap

Thanks for helping out! Bug reports, ideas and pull requests are all welcome.

## Reporting bugs and asking for features

Open an [issue](https://github.com/codeofmario/wiremap/issues/new/choose) and pick a template. For bugs, include your Wiremap version and how you run it.

## Your first pull request

1. Look for issues labeled [`good first issue`](https://github.com/codeofmario/wiremap/labels/good%20first%20issue), or open an issue to talk about your idea first.
2. Fork the repo and create a branch from `main`.
3. Set up the project with `make install` and `make dev` — see [docs/development.md](docs/development.md).
4. Follow the backend and frontend rules described there.
5. Add or update tests, then run `make test`.
6. Open a pull request. CI must pass.
